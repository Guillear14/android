# Unidad 3

## Ejercicios

### Ejercicio 1 — Lista de banderas

En [`Ejercicio1`](./Ejercicio1/) está el módulo Gradle `:ud3-ejercicio1`. Muestra una lista vertical de tarjetas con banderas y nombres de países. `modelo/Bandera.kt` define sus datos, `datos/Datos.kt` prepara la lista y `MainActivity.kt` dibuja las tarjetas con `LazyColumn`. También incluye el tema Compose y los recursos de banderas.

### Ejercicio 2 — Banderas seleccionables

En [`Ejercicio2`](./Ejercicio2/) está el módulo Gradle `:ud3-ejercicio2`. Reutiliza la lista de banderas con tarjetas pulsables. El clic se comunica mediante una función de retorno y registra en Logcat el recurso de la bandera seleccionada. Incluye el modelo `Bandera`, los datos de ejemplo y sus imágenes.

### Ejercicio 3 — Tarjetas expandibles

En [`Ejercicio3`](./Ejercicio3/) está el módulo Gradle `:ud3-ejercicio3`. Las banderas aparecen en tarjetas que se pueden expandir y contraer para mostrar contenido adicional. Incluye el modelo `Bandera`, la carga de datos, el estado de expansión y los recursos gráficos.
