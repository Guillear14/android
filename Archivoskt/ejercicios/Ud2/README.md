# Unidad 2

## Ejercicios

### Ejercicio 1 — Calculadora de IVA

En [`Ejercicio1`](./Ejercicio1/) está el módulo Gradle `:ud2-ejercicio1`. Su pantalla Compose permite introducir un precio, elegir un tipo de IVA (21 %, 10 % o 3 %) y ver el precio final formateado como moneda. Las fuentes están en `app/src/main/java/com/example/ud2_ejercicio1/` y los recursos en `app/src/main/res/`.
