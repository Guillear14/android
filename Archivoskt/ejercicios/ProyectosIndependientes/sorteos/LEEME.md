# Examen de Sorteos

Este ejercicio forma parte del proyecto Gradle `Archivoskt` como módulo `:sorteos`. Abre la carpeta raíz `Archivoskt` en Android Studio y ejecuta ese módulo.

Las pantallas, modelos y `ViewModel` están dentro de `app/src/main/java/com/example/sorteos/`. La navegación Compose y el `minSdk` 26 ya están configurados.
